# Business Documents

Confirm the audience, decision or use, source facts, required format, deadline,
and destination. Prefer a simple structure, plain language, and a private local
draft. Keep claims and numbers traceable; label unknowns rather than filling
them with plausible content.

Use the built-in document, PDF, spreadsheet, and presentation tools as needed.
Visually inspect rendered output before calling it complete. Creating a private
file is allowed. Uploading, sharing, changing access, emailing, publishing, or
overwriting another person's file requires approval for the exact destination.
