# Funding Director Skills

The package contains the safe funding operating procedures. Provider-specific
submission mappings and private classroom-derived procedures remain private and
are activated only after review.

| Skill | Why it is needed | Status | Test |
|---|---|---|---|
| operator-onboarding | personalize the operator | ready | complete guided setup |
| calendar-operator | manage schedule safely | ready | read-only calendar test |
| inbox-operator | triage and draft across inboxes | ready | read three subjects |
| proposal-builder | produce clear private proposals | ready | private draft |
| slack-operator | work across allowed Slack channels | ready | list channels |
| funding-director | own the backend funding operation | ready | synthetic case lifecycle |
| file-underwriting | produce a source-backed file analysis | ready | contradictory fixture |
| product-routing | rank active Product Cards | ready | golden routing fixtures |
| submission-operator | prepare and verify approved submissions | ready | one-time approval test |
| offer-comparison | normalize offers without accepting | ready | incomparable-offer fixture |
| founder-handoff | return a concise decision brief | ready | redaction test |
| funding-knowledge-steward | turn authorized training into reviewed drafts | ready | source/provenance test |

New skills belong in `/opt/data/skills/<skill-name>/SKILL.md`. Each one needs a
clear trigger, inputs, procedure, approval boundary, output, and safe test.
