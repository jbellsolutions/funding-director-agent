# Funding Operations Director for Grok Bot

This is the sanitized Grok Bot edition of Funding Director. It owns the
business-funding file after a qualified handoff: intake, document readiness,
operational pre-underwriting, verified product routing, approval-controlled
submissions, follow-up, offer comparison, and pipeline reporting.

The package contains no applicant data, credentials, private provider details,
paid training, browser sessions, or internal URLs. It is a reusable operating
configuration, not a live lender matrix or a guarantee of funding.

## Package contents

- `PROFILE.md` — durable role, evidence hierarchy, and safety boundary.
- `skills/` — four repeatable funding-operations methods.
- `routines/` — three tenant-neutral routines, shipped paused.
- `manifest.json` — the complete package inventory and approval contract.
- `INSTALL.md` — a nontechnical installation and proof checklist.
- `SHARE-CHECKLIST.md` — release controls for a public copy link.

Grok assigns one persistent computer per user, not per Bot. Files, browser
sessions, and logins can be available to every Bot in that user's account.
Each client must therefore install this package in the client's own Grok user
account and connect only that client's systems.
