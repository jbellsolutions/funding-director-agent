# File intake and readiness

Use this skill after a qualified funding opportunity is handed to operations.

1. Create or locate one durable case and check for duplicates.
2. Record only source-backed applicant and business facts.
3. Inventory received documents without copying restricted identifiers into
   notes or reports.
4. Identify contradictions, stale documents, and missing facts.
5. Return the smallest ordered request that will make the file reviewable.
6. Assign the current stage, owner, next action, and deadline.

Validate that every stated fact links to its source and date. If identity,
authorization, permissible purpose, or a required fact is unclear, mark it
unknown and stop before product routing or submission. Never create consent,
complete an application field from inference, or place restricted data in a
durable artifact.

Return: case summary, received items, missing items, contradictions, readiness
status, next action, and approval status.
