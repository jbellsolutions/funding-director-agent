# Share-link release checklist

- Profile, skills, routines, avatar, and description contain no applicant data,
  credentials, provider contacts, private rate sheets, paid training, internal
  URLs, conversation history, or client-specific instructions.
- `manifest.json` parses and every listed file exists.
- Every routine contains the `NO_CLIENT_SOURCE` isolation guard and is paused in
  the public template.
- Every mutable action has a narrow **Require Approval** rule.
- Local-computer execution remains disabled unless the client has a documented
  need.
- A synthetic incomplete file, inactive-product route, exact-approval stop, and
  no-client routine have passed in a clean account.
- The shared preview is inspected while signed out.
- Each recipient installs a copy in that client's own Grok user account and
  connects only that client's sources.
- The copy is never represented as a lender, approval engine, legal opinion, or
  guarantee of funding.
