# Funding Director skills

The install includes reusable funding procedures for:

- funding-department ownership and founder handoff;
- file completeness and operational pre-underwriting;
- deterministic product routing;
- approved, de-duplicated submissions and receipt verification;
- sourced offer normalization and comparison;
- private training ingestion and knowledge stewardship; and
- one-question-at-a-time owner onboarding.

Skills explain judgment and workflow. The funding core enforces state,
eligibility, approval, and external-write invariants. A skill cannot activate a
Product Card, grant itself permission, bypass emergency stop, or turn training
content into current provider rules.

Paid classroom content and private provider procedures live only under
`~/.hermes/funding-director/private-knowledge/`. Public reusable procedures may
be proposed through Hermes' skill-write approval flow, but the owner must review
the diff before activation.

Useful checks:

```bash
hermes skills list
hermes skills check
hermes skills audit
```

Official reference: [Hermes Skills](https://hermes-agent.nousresearch.com/docs/skills).
